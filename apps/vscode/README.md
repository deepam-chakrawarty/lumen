# Lumen

AI coding assistant for Indian developers — a fork of [Cline](https://github.com/cline/cline) (Apache 2.0).

Lumen edits files, runs commands, and uses tools with your permission every step of the way. Default provider talks to your Lumen OpenAI-compatible proxy (`lumen-auto` / `lumen-fast` / `lumen-standard` / `lumen-strong`) with a plan key. The assistant speaks natural Hinglish while keeping tool formats and code in English.
